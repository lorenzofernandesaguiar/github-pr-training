# Requisitos

## 1. Escopo

A aplicação será uma lista de tarefas baseada na web.

## 1.1 Funcionalidades

A aplicação deverá permitir ao usuário:

- visualizar as tarefas;
- adicionar uma tarefa;
- marcar uma tarefa como concluída;
- excluir uma tarefa.

## 1.2 Dados das tarefas

Cada tarefa terá:

- descrição;
- status de conclusão.

## 1.3 Fora do escopo

O projeto não incluirá:

- autenticação de usuários;
- autorização de usuários;
- backend;
- banco de dados;
- busca de tarefas;
- ordenação de tarefas.
